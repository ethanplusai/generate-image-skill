- **mflux upgrades need API re-verification**: the CLI pins mflux==0.18.0 and imports `Flux1`/`ModelConfig` from `mflux.models.flux.variants.txt2img.flux` — this path has churned across mflux versions (docs/READMEs are often stale). When bumping the pin, inspect the installed package (`uvx --from mflux python -c "import ..."`) rather than trusting docs, then run the live smoke test (Task 6 pattern in docs/superpowers/plans/2026-07-16-agentimagegen.md).
- **Unit tests never need the model**: `uvx --with pillow pytest tests/ -v` is the full suite; real generation is verified separately via `scripts/generate.py` (dry-run for logic, live run for inference).
